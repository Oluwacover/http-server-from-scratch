⚙️ Core Architecture

  • Transport ProtocolRaw TCP / Stream Sockets
  • Concurrency ModelFixed ThreadPool (16 Workers)
  • HTTP ParserByte-Level FSM (RFC 9110)
  • Keep-Alive Timeout5.0s / Persistent Socket
  • Transfer-EncodingIdentity & Chunked
  • Safety & DOS Limits8KB Line / 64KB Headers

🔄 FSM Parser Transitions

1. START → METHOD Ingests GET, POST, PUT, DELETE
2. URI → VERSION Parses path, query, enforces HTTP/1.1
3. HEADER_NAME → VALUE Case-insensitive field map
4. BODY_IDENTITY / CHUNKED Reads exact bytes or hex chunks
5. COMPLETE → DISPATCH Passes HttpRequest to Router
